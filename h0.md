## Linuxin perustoimet
```bash
  sudo apt-get update
  sudo apt-get -y dist-upgrade
  adduser oma_nimi
  usermod -aG sudo oma_nimi
```

Asennettu ssh: 
```bash
sudo apt-get install openssh-server
```
Tarkistetaan, että se kuuntelee porttia 22:
```bash
ss -tlnp | grep :22
```
  <img width="650" height="194" alt="image" src="https://github.com/user-attachments/assets/52b154af-df78-49e6-b6fb-b22bd8659203" />

Lisätty sudo-käyttäjä aura ja testattu ssh-yhteys toisella terminaalilla:
<img width="813" height="312" alt="image" src="https://github.com/user-attachments/assets/d5511acb-3377-44e3-b40a-403848e27f8c" />

Nyt kun ssh-yhteys toimii, voin asentaa tulimuurin:
```bash
  sudo apt-get install ufw
  sudo ufw allow 22/tcp
  sudo ufw enable
  sudo ufw status
```
Astuu voimaan buuttauksen jälkeen, sudo reboot. 
Webbipalvelimen asennus, valitsin Apache2:
```bash
sudo apt-get install apache2
sudo ufw allow 80/tcp -> Avataan portti 80 tulimuurista, jotta sivu toimii koneen ulkopuolellakin. Tarkistetaan status:
systemctl status apache2 
curl -I localhost
```
